Chaque chiffre de votre modèle, rapproché du dépôt officiel.

deskstack donne à Claude des données financières gratuites, avec une source pour chaque chiffre, et une équipe de relecture. Un agent construit le modèle, d'autres vérifient chaque chiffre contre le dépôt SEC ou européen, et rien n'est exporté avant votre validation.

Installer en trois étapes

Pas de terminal, pas de compte à créer. Il faut un compte Claude avec l'exécution de code activée ; les rôles demandent un abonnement payant.

  1. Ajouter le connecteur de données

    Dans Claude, ouvrez Paramètres, puis Connecteurs, puis Ajouter un connecteur personnalisé. Collez l'URL, sans connexion.

    Bientôt en ligne

    Le connecteur hébergé n'est pas encore en ligne. Vous pouvez lancer votre propre copie gratuitement en quelques minutes : guide d'auto-hébergement.

  2. Ajouter l'équipe

    Ouvrez Personnaliser, puis Plugins, puis Ajouter une marketplace. Collez ce dépôt, puis installez deskstack.

    https://github.com/joaquimmj/deskstack

  3. Demander un modèle

    Claude construit le DCF, fait vérifier et relire chaque chiffre, puis attend votre accord.

    /deal-team Apple quick-dcf

Une équipe où chaque rôle a une seule tâche

Chaque rôle est un skill avec sa liste de contrôle et un rapport au format fixe. Ils s'enchaînent dans cet ordre, et chacun peut être appelé seul, sur n'importe quel classeur.

  1. /analyst

    Construit le classeur à partir de données sourcées, après avoir validé les hypothèses avec vous.

  2. /associate

    Vérifie chaque chiffre saisi contre le dépôt et dit pourquoi un chiffre ne colle pas.

  3. /vp-review

    Lance 15 contrôles du modèle, puis compare les hypothèses à l'historique déposé.

  4. /md-redteam

    Argumente contre la valorisation et montre ce que suppose le cours de bourse.

  5. /compliance

    Vérifie la mention de non-conseil, les sources et les signes d'information non publique.

  6. /sign-off

    Montre chaque point ouvert et n'exporte qu'après votre accord, avec vos propres mots.

Les relecteurs font un rapport ; ils ne modifient jamais votre fichier. Dans Claude Code et Cowork, ils tournent comme des agents séparés qui ne voient pas comment le modèle a été construit. Ils relisent aussi les classeurs faits avec le plugin financial-analysis d'Anthropic.

Comment on sait que les chiffres sont justes

Précision

100/100

Questions de référence auxquelles l'outil répond exactement comme dans les dépôts, à chaque modification : entreprises américaines et européennes, une banque, des retraitements, une division d'action, des exercices clos en janvier, mars, juin et septembre. Chaque nuit, les réponses sont relues dans les dépôts par des outils indépendants.

Comment fonctionne le jeu de référence

Benchmark

Nous mesurons combien de chiffres sont faux ou sans source quand Claude construit un modèle avec la recherche web seule, avec les données deskstack, et avec les relecteurs deskstack en plus, notés automatiquement contre les dépôts. Premiers résultats, sur 50 entreprises (un DCF chacune, Claude Sonnet 5.5) : avec la recherche web seule, 20 chiffres publiés sur 573 étaient faux (3,5 %), vérifiés à la main contre les dépôts. Avec les données deskstack, aucun, pour un tiers du coût. Ce zéro tient en partie à la méthode (la notation vérifie contre les mêmes données) : l'analyse explique comment ces données sont vérifiées par ailleurs, et ce que le run a trouvé de faux dans deskstack. Chaque transcription est publique.

Ce que l'outil ne fait pas

  • Pas de cours de bourse ni de consensus : une capitalisation demande un cours que vous fournissez.
  • La couverture européenne est partielle et annuelle ; les émetteurs allemands ne sont pas encore dans la base publique.
  • Les banques et assureurs sont signalés : un DCF classique ne s'y applique pas.
  • Les relectures réduisent les erreurs mais ne remplacent pas un relecteur humain. Tout reste un brouillon jusqu'à votre validation.
