How the figures are checked

  • Each submitted figure is scored against the filing it should come from, then every one the scorer calls wrong is read by hand and classified. The analysis of each run lists every case.
  • The setups with deskstack read the data they are scored against, so their 0 is partly by construction. deskstack's data is checked separately: a golden set of questions with known answers on every push, and a nightly re-read of each answer from the filing itself with independent parsers, edgartools for SEC filings and Arelle for European reports.
  • Generated from bench/results by server/bench/leaderboard.ts. The runner, the frozen company set and the method are in bench/.
